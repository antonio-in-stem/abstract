# Changelog

## 1.7.2

- Rewrote the extension page around object definitions, variations and practical
  authoring tasks. Moved detailed behavior to the bundled authoring reference.
- Removed the README image that depended on remote repository access. The
  extension uses its packaged Abstract logo as the native VS Code icon.

## 1.7.1

- Updated the extension identity with the owner's supplied Abstract logo.
- Rewrote the product introduction and installation instructions.
- Aligned package license metadata with the MIT source license and included
  separate terms for the new brand artwork.
- Documented workspace-level file associations for multi-root exercises and
  added regression coverage for conflicts with another language.

## 1.7.0

- Added completion, highlighting and hover help for explicit `calc(...)`
  arithmetic in Abstract 1.2.

## 1.6.1

- Added hover explanations for defaults, numeric ranges and list cardinality.
- Distinguished instance keys, bare values and tuple columns.

## 1.6.0

- Added contextual syntax documentation that works without the compiler.

## 1.5.0

- Added formatting, compiler-owned references and rename, asset and tuple
  completion, and evaluated-value hover support.
