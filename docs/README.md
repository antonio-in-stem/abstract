# Abstract documentation

Start with the [learning path](learn/README.md) if you are new to the language.
The [language guide](language.md) explains schemas, instances, reuse, logic,
resources, and model `versions` in a practical order. The [AI guide](ai/README.md)
is a compact authoring checklist for assisted work.

## Reference

- [Language specification](reference/specification.md): normative syntax,
  semantics, diagnostics, and conformance requirements.
- [Grammar](reference/grammar.ebnf): lexical and syntactic grammar.
- [Syntax reference](reference/syntax.md): lookup-oriented source reference.
- [Arithmetic](reference/arithmetic.md): `calc(...)` expressions and limits.
- [Compiled data](reference/compiled-data.md): JSON, YAML, RAW, and overlays.
- [Public data](reference/public-data.md): author-selected scalar export.
- [Editor protocol](reference/editor-protocol.md): compiler analysis protocol.
- [Compatibility](compatibility.md): component boundaries and wire contracts.
- [Releasing](releasing.md): artifact and release checks.

Use [tutorials](../examples/README.md), [feature examples](../examples/features/README.md),
and [exercises](../examples/exercises/) to learn by compiling real projects.
