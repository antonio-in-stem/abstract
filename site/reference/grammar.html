This page is the practical reading of docs/GRAMMAR.ebnf, which is normative and defines every rule name used in the specification. Where this page is shorter than the grammar, the grammar wins.

Lexical conventions

RuleDefinition
EncodingUTF-8. A byte-order mark at offset 0 is removed before lexing and has no other effect.
Line terminatorsLF and CRLF, each one terminator. A lone CR is E210.
WhitespaceSpace and tab separate tokens. Indentation carries no meaning: two programs differing only in leading whitespace compile identically.
Comments// to the end of the physical line, only at line start or immediately after a space or tab, never inside a quoted string.
Longest matchAt each position the lexer takes the longest match, except that . followed by . is always .. — so 1..3 is 1, .., 3.
Adjacency::, .., ${, $$, derive?, a field head’s [], a size token, an annotation’s (, and the #/@/&/$ that introduces a construct are single lexemes with no internal whitespace.

Identifiers

ident_start   = letter | digit | "_"
ident_char    = letter | digit | "_" | "-"
identifier    = ident_start , { ident_char }        (* must not end with "-" *)
schema_name   = letter , { letter | digit | "_" }

Identifiers are ASCII only (E206) and are normalised: ASCII-lowercased, then - replaced by _. Schema names are not normalised and are compared exactly. Purely numeric identifiers are legal and are ordinary names, not indices.

Line joining

The lexer keeps a value-bracket stack for ( ), [ ] and the { } of a multi-path key list. While that stack is non-empty a line terminator produces nothing and the logical line continues; while it is empty a line terminator ends the statement.

A block brace — the { of a schema, a group, a logic block or an instance body block — is matched against its } but is never pushed onto that stack, so it joins no lines. A block’s { must be the last token of its line and its } the first token of one.

There are exactly two further continuation rules: inside a header tag list when the line so far ends with ,, and inside a logic block when the next token after the terminator is else. A trailing , at bracket depth 0 does not continue a statement — it is E442.

tags: [
    core,
    public
]                      // continues: the '[' is open

tags: core, public     // one statement, one line

tags: core,            // E442: trailing comma at depth 0
public

schema Label {         // a block brace joins no lines
    caption: text
}

Values

value         = list_value | bare_list
bare_list     = single_value , { "," , single_value }
list_value    = "[" , [ single_value , { "," , single_value } , [ "," ] ] , "]"
single_value  = quoted_string | tag_object | bare_text

tag_object    = "#" , identifier , [ "(" , [ tag_arg , { "," , tag_arg } ] , ")" ]
tag_arg       = tag_arg_key , ":" , tag_arg_value | identifier
tag_arg_key   = identifier , { "." , identifier }

A bare_text token is the raw, undecoded lexeme of an unquoted value. It never begins with ", # or [; contains no line terminator, no comment start and no , at bracket depth 0; has its leading and trailing whitespace removed; and, in a body statement, ends before any trailing annotation list. An empty right-hand side is E210.

"quoted string"           // escapes: \" \\ \n \r \t  -- and nothing else
123                       // an integer literal where an int is declared
19.5                      // a float literal; 1.21.5 stays text
true / false              // bool
[one, two, three]         // list; may span lines while brackets are open
#tag        #tag(field: value, flag)
./art/{hero,thumb}.png    // brace pattern, on a file/image list field
flags: hat_*              // enum wildcard, in one of three positions
./sets/$id/icon.png       // $field / ${field} interpolation; $$ is a literal $

Template files

template_file = { NL } , { template_item }
template_item = ( versions_decl | schema_decl | logic_decl ) , { NL }

versions_decl = "versions" , version_number , ".." , version_number , NL

schema_decl   = "schema" , schema_name , "{" , NL , field_list , "}" , NL
field_decl    = ( scalar_field | group_field ) , { NL }

scalar_field  = field_head , ":" , type_expr , { field_modifier } ,
                [ "=" , default_value ] , NL
group_field   = field_head , { field_modifier } , "{" , NL , field_list , "}" , NL

field_head    = identifier , [ "[" , [ cardinality ] , "]" ]
cardinality   = uint , ".." , [ uint ]
field_modifier = "@optional" | "@tag" | version_annotation

Types

text_type          = "text"  , [ "(" , [ int_range_list ]   , ")" ]
int_type           = "int"   , [ "(" , [ int_range_list ]   , ")" ]
float_type         = "float" , [ "(" , [ float_range_list ] , ")" ]
bool_type          = "bool"
enum_type          = "enum"  , "(" , identifier , { "," , identifier } , ")"
file_type          = "file"  , "(" , extension , { "," , extension } , ")"
image_type         = "image" , "(" , image_alt  , { "," , image_alt  } , ")"
image_alt          = extension , [ ws , size_token ]
size_token         = ( uint | "*" ) , "x" , ( uint | "*" )
ref_type           = "ref" , "(" , schema_name , ")"
nested_schema_type = "$(" , schema_name , ")"

A type keyword must be immediately followed by ( when it takes arguments: text (1..40) with a space is E304. The size token is one lexeme, so image(png128x128) is a single extension and is E307, while image(png 128 x 128) is E308.

Annotations

since_annotation   = "@since"   , "(" , version_number , ")"
removed_annotation = "@removed" , "(" , version_number , ")"
annotation_list    = version_annotation , [ version_annotation ]

An annotation list appears in exactly three places: as a field modifier, at the end of a body statement, and at the end of an instance header. Anywhere else — on a header tag, a clone statement or a body block — it is E437. The ( is what separates @since(2) from the header tag @since.2 and the flag @since; the parser never looks further than that character.

Logic blocks

logic_decl       = "logic" , schema_name , "{" , NL , logic_body , "}" , NL

derive_statement  = ( "derive" | "derive?" ) , logic_path , "=" , derive_expr , NL
derive_expr       = logic_path | length_call | version_builtin | loop_variable | value
require_statement = "require" , condition , "else" , "throw" , quoted_string , NL
if_statement      = "if" , condition , block ,
                    { "else" , "if" , condition , block } , [ "else" , block ]
for_statement     = "for" , loop_variable , "in" , iterable , block
iterable          = logic_path | list_value
condition     = or_condition
or_condition  = and_condition , { ( "or" | "||" ) , and_condition }
and_condition = not_condition , { ( "and" | "&&" ) , not_condition }
not_condition = [ "not" | "!" ] , comparison
comparison    = operand , comparison_op , operand
              | operand , "contains" , operand
              | operand , "exists"
              | operand
comparison_op = "==" | "!=" | ">=" | "<=" | ">" | "<"
operand       = "(" , condition , ")" | length_call | version_builtin
              | logic_path | loop_variable | quoted_string | number | bool_literal
length_call   = "length" , "(" , ( logic_path | loop_variable ) , ")"
logic_path    = root_path | loop_path
root_path     = "." , logic_segment , { "." , logic_segment }
loop_path     = loop_variable , "." , logic_segment , { "." , logic_segment }
logic_segment = ( identifier | loop_variable ) , [ "[" , uint , "]" ]

The index is read-only, and a loop-variable segment is a read position: a derive target containing one is E520. version is a bare word — a field is always written with a leading ., a loop variable with a leading $, and a quoted "version" is literal text, so the three never collide.

Instance files

instance_file    = { NL } , { instance }
instance         = instance_header , { clone_statement } , { body_item }

instance_header  = schema_name , "::" , [ header_tag_list ] , [ annotation_list ] , NL
header_tag_list  = header_tag , { "," , header_tag }
header_tag       = "@" , identifier , [ "." , header_tag_value ]
header_tag_value = quoted_string | bare_header_value

clone_statement  = "&" , instance_id , [ "." , ( "*" | path ) ] , NL

body_item        = body_statement | body_block
body_statement   = assignment , [ annotation_list ] , NL
body_block       = path , "{" , NL , { body_item } , "}" , NL

assignment       = tuple_array_assignment | multi_path_assignment | path_assignment
path_assignment  = path , ":" , value
multi_path_assignment
                 = path , "." , "{" , identifier , { "," , identifier } , "}" , ":" , value
tuple_array_assignment
                 = path , "(" , identifier , { "," , identifier } , ")" , ":" ,
                   ( tuple_row , { "," , tuple_row }
                   | "[" , tuple_row , { "," , tuple_row } , [ "," ] , "]" )
tuple_row        = "(" , tuple_cell , { "," , tuple_cell } , ")"
tuple_cell       = quoted_string | bare_text

Assignment, multi-path, body-block and clone paths admit no index syntax: a segment written name[0] is E316. A bare_header_value is a bare_text that additionally contains no depth-0 @ and no depth-0 ,.

Reserved words

PositionWords
Top level of a .abt fileschema, logic, versions
Type positiontext, int, float, bool, enum, file, image, ref
Modifier position@optional, @tag, @since, @removed
Logic statement positionderive, derive?, require, if, else, for
Logic expression positionin, not, and, or, contains, exists, length, version, true, false

Keywords are recognised only where they are meaningful; none is reserved as a field name, an enum member or an instance id. Operator spellings: == != < <= > >= && || !. Punctuation with meaning: : :: . , = ( ) [ ] { } [] @ # & $ ${ $$ * ? .. //.

Limits

Each of these is 64, and exceeding one is E209: bracket nesting in a value; segments in an assignment, clone or logic path; schema group nesting and $(Schema) nesting in one compiled object; if/for nesting in one logic block; clone chain length; and the depth of the emitted document. An implementation must never abort, panic or crash on any input.

For how failures are reported, read diagnostics.
