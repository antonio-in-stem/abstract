Comments

// This is a comment.
name: "http://example.test" // comments do not split quoted strings

Schema blocks

schema Name {
    field: type
    field: type = default
    field: type @optional
    field[]: type

    group {
        child: type
    }
}

Types

text(1..40)
int(0, 2..15)
enum(draft, active, retired)
file(png, jpg, webp)
$(OtherSchema)

Modifiers

ModifierMeaning
[]The field is a list.
@optionalThe field may be omitted.
@tagThe field receives shorthand tag values such as #search.
= valueThe field receives a default when omitted.

Instance blocks

Template :: @field.value, @other.value
    field: value
    nested.field: value

Logic blocks

logic Template {
    derive .computed_field = value

    if .field == "value" {
        require .other_field exists
            else throw "Message for the author."
    }

    for item in .items {
        require item.value exists
            else throw "Every item needs a value."
    }
}
SyntaxMeaning
if condition { ... }Runs nested rules when a condition is true.
derive .path = valueWrites a derived value onto the current instance.
require condition else throw "message"Fails compilation when the condition is false.
for name in .path { ... }Loops over array values and binds a variable.
existsChecks that a path resolves to at least one value.
containsChecks array or projected path membership.
== != > >= < <=Compares strings or integers.
and or && ||Combines conditions.

For how failures are reported, read diagnostics.
