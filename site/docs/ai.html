For AI collaborators

How to work in Abstract without making a mess.

Abstract is friendly to AI because the schema is explicit, the output is readable, and the compiler can check the work. This page is the operating manual.

AI guide
Read first Editing rules Generation checklist Prompt template Limits

Read first

Before editing instances, read all relevant .abt schema files. Before changing a schema, compile the project once so you understand the current valid shape.

  • Use schemas as the source of truth.
  • Use instances as authored source.
  • Treat compiled JSON/YAML as generated output unless a human explicitly asks you to inspect it.
  • Run abstract lint after edits.
  • Run abstract <object.ab> <Template.abt> JSON|YML true when the compiled artifact must be refreshed.

Editing rules

Do not guess enum values. They are declared in the schema. Do not invent nested fields unless the schema allows them. If a value needs spaces, quote it. If several values are mostly the same, prefer cloning over copy-pasting a full instance.

Generation checklist

  1. Find the target template with abstract templates <path>.
  2. Read the template schema.
  3. Create or edit .ab files, not compiled JSON/YAML output.
  4. Use tuple arrays for table-like repeated values.
  5. Use tagged shorthand only when the schema has @tag.
  6. Run abstract lint <path>.
  7. Compile only after lint passes.

Useful prompt template

You are editing an Abstract project.
First read all .abt schemas.
Then edit only .ab authored files unless I ask for schema changes.
After editing, run:
    abstract lint <project>
If lint passes, run:
    abstract <object.ab> <Template.abt> JSON true
Summarize changed instances and any schema assumptions.

Limits to respect

Logic blocks can derive values and evaluate validation rules. Keep domain-specific derivations inside the relevant .abt template, not in external tooling. If you see a mismatch between source and output, regenerate from source instead of editing the compiled JSON or YAML by hand.

The good AI workflow is simple: read schema, edit source, lint, compile, explain. Anything more clever should earn its keep.
