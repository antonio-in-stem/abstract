Instance authoring

Write the data people will actually maintain.

Instances are where Abstract tries to feel good. The syntax rewards clean repetition, compact tables, and small declarations that are still easy to review.

Instance header

The header names the template and optionally assigns short values with @field.value.

Product :: @id.atlas, @status.active, @tier.premium

If no explicit id is assigned, the compiler uses the file stem. A file named atlas.ab becomes id: "atlas".

Plain assignments

name: Atlas Search
release_year: 2026
tags: [core, public, ai_ready]

Unquoted bare words become strings. Use quotes when a value needs spaces, punctuation, or deliberate casing.

Dotted paths

Dotted paths fill nested objects without making the source visually heavy.

owner.team: Knowledge Systems
owner.contact: systems@example.com

Tagged objects

When a schema marks a child field with @tag, instances can use #name shorthand. Parentheses add overrides.

capabilities: [#search, #sync(availability: beta), #analytics]

Tuple arrays

Tuple arrays are for data that reads like a table. The left side declares the destination field and the columns.

copy(key, value):
    (en_us, "Welcome"),
    (es_es, "Bienvenido"),
    (fr_fr, "Bienvenue")

The compiler emits an array of objects. If the field is named lang, the RAW field becomes lang_values for readability.

Multi-path assignment

Use braces on the left side to assign one value to multiple sibling keys.

thresholds.{warning, critical}: 90

File pattern expansion

A brace pattern that looks like file paths expands into an array. This is intentionally simple and works well for small asset families.

images: ./assets/{hero,thumbnail,card}.png

Wildcard expansion

Wildcard expansion works against tagged enum groups. A value such as es_* expands to every allowed enum value that starts with es_.

lang(key, value): (es_*, "Hola")

Clones

Put &target.* before an instance to clone a compiled instance, then override fields in the new one.

&atlas.*

Product :: @id.beacon, @status.draft
    name: Beacon Export

Clone targets are resolved by instance id. Cycles are rejected.
