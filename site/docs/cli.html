Command line

The compiler is small on purpose.

Abstract ships as a single CLI. It reads projects, validates data, prints JSON or YAML, writes files only when asked, and lists known templates.

Install

Download the Windows executable from this site and install it (adds it to your PATH):

powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Prebuilt abstract-windows-x64.exe

Or build from source on any platform with Rust installed:

# Windows
powershell -ExecutionPolicy Bypass -File scripts\install.ps1

# Linux / macOS
sh scripts/install.sh

abstract --version

abstract init <directory>

Scaffolds a working project: pack.ab, schemas under data/templates/, a sample instance, and an assets/ folder. The scaffold compiles immediately and demonstrates floats, bools, images, and derive?.

abstract init my-pack
abstract compile my-pack JSON

abstract compile <path> [JSON|YML|RAW] [true] [--out <file>]

Compiles a file or directory. Directories are read recursively (.abt and .ab), sources sort by path, every instance is validated, and JSON prints by default. RAW emits the human-oriented data: [...] format.

abstract compile example JSON
abstract compile example YML true          # also writes example/abstract.yml
abstract compile example RAW --out out.abraw

abstract <object.ab> [Template.abt ...] JSON|YML|RAW [true]

Direct form: compiles explicit source files. Sibling files load as context (clones resolve), but only the requested instances are emitted and validated.

abstract object.ab Template.abt JSON
abstract object.ab Template.abt YML true

abstract lint <path>

Validates the same project as compile but discards output. This is the command for pre-commit hooks and CI jobs. Success prints abstract: ok.

abstract templates <path>

Prints every schema name discovered in the project: useful for editor tooling and scripts.

abstract bundle <path> --key <k> [--out <file.abx>] [--plain]

Compiles a project and seals the JSON result into a tamper-evident .abx container (ChaCha20-Poly1305). The key is a passphrase (hashed with SHA-256) or exact bytes as hex:<64 digits>. --plain writes an unencrypted bundle for debugging. See Java & bundles.

abstract bundle my-pack --key "release passphrase" --out my-pack.abx

abstract unbundle <file.abx> [--key <k>]

Opens a bundle and prints the JSON payload. A wrong key or a modified byte fails with an authentication error.

Options

FlagEffect
--skip-assetsSkips on-disk checks (file(...) existence, image(...) probing, file-path exists). For authoring on machines without the binary assets.
--allow-unknownAccepts instance fields the schema does not declare (lenient migration mode).
--out <file>Writes output to an explicit path instead of the default sibling file.
--key <material>Bundle key: passphrase or hex:<64 hex digits>.
--plainUnencrypted bundle (debugging only).

Exit behavior

On success, the CLI exits with code 0. On failure, it prints an error beginning with abstract: and exits with code 1. Parse errors include the source path and line (stickers/bad.ab:3: ...); validation errors include the source path and the field context.
