Command line

The compiler is small on purpose.

Abstract ships as a single CLI. It reads projects, validates data, prints JSON or YAML, writes files only when asked, and lists known templates.

Install

Download the Windows executable from this site, or build from source with Rust.

cargo build --release
target\release\abstract.exe --version

For local development, install it into Cargo's binary directory:

cargo install --path .
abstract --version

abstract <object.ab> <Template.abt> JSON|YML [true|false]

Compiles explicit source files, validates every instance, and prints standard JSON or YAML to stdout.

abstract object.ab Template.abt JSON
abstract object.ab Template.abt YML true

The optional boolean controls file writing. true writes a sibling .json or .yml next to the first input. Missing or false prints only.

ArgumentMeaning
<path>A single .ab/.abt file or a directory containing Abstract files.
JSON|YMLOutput format.
true|falseOptional write flag. Defaults to false.

abstract compile <path> [JSON|YML] [true|false]

Compiles a file or directory. If the path is a directory, the compiler recursively reads .abt and .ab files, sorts sources by path, validates all instances, and prints JSON by default.

abstract compile example JSON
abstract compile example YML true

abstract lint <path>

Validates the same project as compile, but discards output. This is the command to put in a pre-commit hook or CI job.

abstract lint example

A successful lint prints:

abstract: ok

abstract templates <path>

Prints every schema name discovered in the project. This is useful for editor tooling, scripts, and quick checks when a project grows.

abstract templates example

abstract --help

Prints the command summary built into the executable.

abstract 0.1.0

USAGE:
    abstract <object.ab> <Template.abt> JSON|YML [true|false]
    abstract compile <path> [JSON|YML] [true|false]
    abstract lint <path>
    abstract templates <path>

abstract --version

Prints the current compiler version.

abstract 0.1.0

Exit behavior

On success, the CLI exits with code 0. On failure, it prints an error beginning with abstract: and exits with code 1. Errors include the source path when the compiler can attach the problem to a file.
