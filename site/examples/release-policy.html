Release policy.

How much a schema can say on its own, and where a logic block takes over.

Project: docs/examples/release-policy. A small object that shows how much a schema can say without any extra syntax: an enum vocabulary, a list that must not be empty, a default, an optional note, and one rule that only makes sense as logic.

data/templates/Policy.abt

schema Policy {
    level: enum(open, guarded, sealed)
    reviewers[1..]: text(1..40)
    window_days: int(1..90) = 14
    notes: text(1..120) @optional
}

logic Policy {
    require .level != "sealed" or length(.reviewers) >= 2
        else throw "A sealed policy needs at least two reviewers."
}

reviewers[1..] is a list with a minimum cardinality: an empty list is E445, and an absent one is E411 because the field is required. The require expresses what the schema cannot — a relationship between two fields.

data/policies/default_policy.ab

Policy :: @id.default_policy
    level: guarded
    reviewers: platform, security
    window_days: 30

reviewers: platform, security is a bare comma-separated list — the same thing as [platform, security].

data/policies/sealed_policy.ab

Policy :: @id.sealed_policy
    level: sealed
    reviewers: [platform, security]
    notes: "Requires two sign-offs before release."

The note is quoted because it contains no comma but does end in a period; quoting is always safe. window_days is absent, so its default of 14 is filled in.

      "window_days": 14,
      "notes": "Requires two sign-offs before release."
    }
  ],
  "overlays": []
}

notes appears only on the second object: an absent optional field is omitted, never emitted as null or as an empty string.

Break it

Policy :: @id.thin_policy
    level: sealed
    reviewers: platform
data/templates/Policy.abt:9:9: error[E515]: Policy logic: A sealed policy needs at least two reviewers.
  note: data/policies/thin_policy.ab:1:1: instance 'thin_policy' declared here.
  note: compiling version 1.

The diagnostic points at the require in the template and names the instance that failed it. Exit code 1; nothing is written to stdout.
