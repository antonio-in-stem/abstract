Product catalog.

Three products, one schema, and the two clone forms: a full clone with an override, and a partial clone of one subtree.

Examples
All examples Product catalog Release policy Sticker pack

Project: docs/examples/clones. It shows the shape most catalogs end up with — a required title, a defaulted status, a required owner group and a keyed capability list — and how a variant is written by cloning rather than by copy-paste.

data/templates/Product.abt

schema Product {
    title: text(1..60)
    status: enum(draft, active, retired) = draft
    owner {
        team: text(1..50)
        contact: text(1..80)
    }
    capabilities[] {
        id: enum(search, sync, export) @tag
        availability: enum(alpha, beta, stable) = stable
    }
}

data/products/atlas.ab

Product :: @id.atlas, @status.active
    title: Atlas Search
    owner.team: Knowledge Systems
    owner.contact: systems@example.com
    capabilities: [#search, #sync(availability: beta)]

data/products/beacon.ab

Product :: @id.beacon
&atlas.*
    title: Beacon Export

A full clone, then one override. beacon inherits atlas’s status, owner and capabilities; template and id are never cloned.

data/products/probe.ab

Product :: @id.probe
&atlas.owner
    title: Probe
    capabilities: []

A partial clone copies just the owner subtree. status is absent, so its default draft is filled, and capabilities is required, so it is given explicitly as an empty list — a present value, not an absence.

The arrays are shown compactly here to keep the page readable; the stored expectation in docs/examples/clones/expected.json is the byte-exact form, with one member per line.

What to take from it

  • Objects are ordered by (template, id), so atlas, beacon, probe — not file order.
  • Keys follow the schema’s declaration order, not the order the assignments were written.
  • A default fills in before logic runs; an absent optional field would simply be missing.
  • A clone copies the source’s authored data, so it never picks up values that only a default or a derive would have supplied.
