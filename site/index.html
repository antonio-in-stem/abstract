Schemas, instances, compiled data

Data that reads like it was meant to be written.

Abstract is a compact language for data with rules. You describe the shape once, write instances in a friendly syntax, and compile them into stable JSON or YAML.

A schema is the planet. Instances are the settlements. JSON or YAML is the map you can hand to any tool.

Why it exists

Configuration got too important to stay shapeless.

Most projects begin with a few neat config files. Then rules appear: IDs must be unique, variants must match a list, translated values need the same keys, paths need known extensions. Abstract makes those rules part of the authoring language instead of burying them in memory or review comments.

Write with constraints

Use text, int, float, bool, enum, file, image, groups, lists, defaults, and tags to describe what valid data looks like before anyone writes instances.

Compile before shipping

The compiler checks every instance against its schema. Typos in field names, bad enum values, missing files, images with the wrong size or lying extensions, clone cycles, and range mistakes fail early, with suggestions.

Ship it sealed

Output is standard JSON, YAML, or RAW for pipelines, and abstract bundle seals compiled data into encrypted, tamper-evident containers a zero-dependency Java runtime opens on Java 8+.

A tiny tour

From schema to JSON in three files.

Abstract is not trying to replace a programming language. It is the missing middle between free-form config and code: a place where data can be authored with taste, then checked with teeth.

schema Product {
    id: text(1..40)
    status: enum(draft, active, retired)
    release_year: int(2000..2100)
}

Get it

Download the compiler or build it from source.

The Windows build is included with this site. The Rust source lives beside the docs, so the language can be published as its own repository without carrying application-specific baggage.

Windows executable

Download abstract.exe, then install it onto your PATH:

powershell -ExecutionPolicy Bypass `
  -File scripts\install.ps1 `
  -Prebuilt abstract-windows-x64.exe

Download for Windows

Build from source 
# Windows
powershell -File scripts\install.ps1

# Linux / macOS
sh scripts/install.sh

Needs Rust; no other dependencies.

Start a project 
abstract init my-pack
abstract compile my-pack JSON
abstract lint my-pack

Abstract is a young language. The promise is not that it already does everything. The promise is that the core idea is small enough to understand and strong enough to build on.
