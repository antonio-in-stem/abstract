Schemas, instances, compiled data

Data that reads like it was meant to be written.

Abstract is a compact language for data with rules. You describe the shape once, write instances in a friendly syntax, and compile them into stable JSON, YAML or RAW.

Start learning Use the CLI Read the language guide

Version 1.0.0 is the first stable definition of the language: a normative specification, stable error identifiers, byte-exact output, and one project that carries every version of its data.

Product :: @id.atlas, @status.active

A schema is the planet. Instances are the settlements. JSON or YAML is the map you can hand to any tool.

Why it exists

Configuration got too important to stay shapeless.

Most projects begin with a few neat config files. Then rules appear: ids must be unique, variants must match a list, translated values need the same keys, paths need known extensions and real dimensions. Abstract makes those rules part of the authoring language instead of burying them in memory or review comments.

Write with constraints

Nine types — text, int, float, bool, enum, file, image, ref, $(Schema) — plus groups, lists with cardinality, defaults and tags describe what valid data looks like before anyone writes an instance.

Compile before shipping

Every instance is checked against its schema. Typos in field names, bad enum values, missing files, images with the wrong size or a lying extension, clone cycles, duplicate ids and range mistakes all fail early, with an identifier, a position and a suggestion.

Carry every version

versions 1..3, @since(n) and @removed(n) let one project describe several releases at once. The compiled document holds the newest version plus overlays for the older ones.

A tiny tour

From schema to JSON in three files.

Abstract is not trying to replace a programming language. It is the missing middle between free-form config and code: a place where data can be authored with taste, then checked with teeth.

This project is checked in as docs/examples/readme-tour, stored with the exact document it compiles to.

versions 1..2

schema Pack {
    title: text(1..40)
}

schema Product {
    title: text(1..60)
    status: enum(draft, active, retired) = draft
    price: float(0..9999)
    icon: image(png 128x128)
    pack: ref(Pack)
    glow: bool @since(2) = false
    owner {
        team: text(1..50)
        contact: text(1..80) @optional
    }
    capabilities[] {
        id: enum(search, sync, export) @tag
        availability: enum(alpha, beta, stable) = stable
    }
}

Product :: @id.atlas, @status.active
    title: Atlas Search
    price: 19.5
    icon: ./textures/$id.png
    pack: core
    owner.team: Knowledge Systems
    capabilities: [#search, #export(availability: alpha)]

Get it

Download the compiler or build it from source.

The Windows build ships with this site. The Rust source lives beside the docs and has no dependencies at all, so the language can be published as its own repository.

Windows executable

Download abstract.exe, then install it onto your PATH:

powershell -ExecutionPolicy Bypass `
  -File scripts\install.ps1 `
  -Prebuilt abstract-windows-x64.exe

Download for Windows

Build from source 
# Windows
powershell -ExecutionPolicy Bypass -File scripts\install.ps1

# Linux / macOS
sh scripts/install.sh

Needs Rust; no other dependencies.

Start a project 
abstract init m-project
abstract compile m-project JSON
abstract lint m-project

Abstract 1.0 is small on purpose. The promise is not that it does everything, but that everything it does is defined, positioned and reproducible.
