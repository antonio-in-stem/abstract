# Abstract

Abstract is a declarative modeling language for schema-backed families of
objects. The `abstract` binary validates `.abt` definitions and `.ab` instance
files, then compiles them to JSON, YAML, or RAW output.

This package provides both the `abstract_lang` library and the `abstract`
command-line compiler. The language specification, examples, and editor
extension are maintained in the source repository:
<https://github.com/antonio-in-stem/abstract>.

Build and install from a checked-out repository with:

```sh
cargo install --path . --locked
```
